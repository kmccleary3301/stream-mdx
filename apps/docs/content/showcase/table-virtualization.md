# Table row virtualization

Open `/showcase/table-virtualization` to render 50–500 rows. Every fifth description has three lines; other rows contain one or two lines. Change the row count, maximum height, overscan, or opt-in checkbox while the table is mounted.

Use "Scroll to Last Row" to reach the final record. The page displays its expected `PK-` ID above the table. "Scroll to Top" returns to the first record. Disabling virtualization renders every row without spacers.
